Refresh setup

To refresh on demand, save a GitHub token that can run the update job.

  1. Create a fine-grained token
  2. Resource owner: afwright
  3. Repository access: Only select repositories, then anwtest
  4. Permissions: Repository, Actions, Read and write
  5. Expiration: 30 days
  6. Paste it below and tap Save

The token stays only in this browser, is never sent anywhere except api.github.com, and can only run workflows in this one test repo.

Sources: lift, run and snow data from the public Whistler Blackcomb terrain status and snow report pages, refreshed by a scheduled job; forecast from Open-Meteo.
