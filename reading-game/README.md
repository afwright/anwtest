# Treasure Island Readers ⛵

A play-based reading game for two young readers: **Little Captain** (pre-reader, around age 4) and **Big Captain** (early reader, around age 7).
The aim is to teach *why* reading matters as well as *how* to read: in the "Reading Quest" missions, the child can only get the treasure, stay safe, make the pancakes or deliver the parcel by reading.

## Play it
Open `index.html` in Safari, Chrome or Edge. It needs no install, no internet and no accounts. On an iPad, use Share → **Add to Home Screen** so it opens full-screen.
Turn the volume up: every prompt is spoken aloud.

Difficulty adapts per skill (levels 1–3) from each child's recent accuracy.

## Points
- 🪙 **Coins:** 3 for a correct answer on the first try, 1 for getting there later, never taken away. Coins are spent in the Harbor Shop on boat decorations.
- ⭐ **Stars and stickers** for every finished voyage, collected in the sticker book.
- **Ranks:** Deckhand → Sailor → First Mate → Captain → Admiral.
- 🦸 **Reading Superpowers** earned in Reading Quest are listed on the "Why Read?" scroll on the map.

## Grown-ups panel
Hold the ⚙️ gear for 3 seconds to open it. From there you can:
- rename the kids and change their avatars and tracks;
- set the speech speed;
- see accuracy and level for each skill;
- see quiz history;
- reset progress.

Progress is saved in the browser on that device only.

## Tip
The game sets up the "why"; you make it stick. When reading pays off in real life (a dock sign, a recipe, a game menu), say so out loud.
